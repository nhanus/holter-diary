First versioned preview of Holter Diary, a small offline diary for activities and
symptom times during Holter monitoring.

- German and English interface with quick notes and symptom markers.
- Local storage, offline use and explicit updates that protect unfinished input.
- Optional patient details and recorder-clock correction.
- PDF and text reports with compact, multi-page output.
- A clearer update indicator and the installed version shown in App updates.
- Automated, validated release packages with checksums and source identification.

This is a prerelease. Real Android restart, offline and accessibility acceptance
remains in progress. The app records observations; it does not interpret ECG data.

Use the attached app archive for hosting. GitHub's source archives contain source
code and are not ready-to-serve app packages. Installation and device-check steps
are documented in `docs/DEPLOYMENT.md`.
