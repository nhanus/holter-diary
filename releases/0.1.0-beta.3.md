# Holter Diary 0.1.0-beta.3

## Faster note capture on small screens

- Write directly in the diary without opening another screen.
- Keep Save and Discard together inside the note card, reachable above the keyboard.
- Avoid moving controls on focus, changing spacing during scrolling, and overlaps with the header.
- Find report export beside the diary heading; immediate symptom marking remains a separate action.
- Edit existing entries with scrollable fields and a persistent action row.
- Improve large-text and narrow-screen handling without changing stored notes or timestamps.

Existing diaries, language preferences, offline storage and the installed app identity are preserved. No new permissions or dependencies are required.

This is a prerelease. Keyboard layouts and accessibility settings vary between devices; please check the updated capture flow on your phone.
