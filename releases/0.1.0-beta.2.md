The project website and installed diary now have separate entry points and build inputs.

- A bilingual introduction, illustrated guide and FAQ explain capture, clock differences, local storage, installation and PDF export.
- The diary lives under `app/`; installation opens the diary directly. Website language links can open it in German or English.
- Existing installations retain their update channel and stored diary. Old launch URLs continue to reach the diary offline and in standalone mode.
- Website builds copy a selected published app release without rebuilding it. Documentation changes alone do not create an app update.

The app archive now contains `app/` and the root compatibility worker and manifest. Keep the same origin and base path when upgrading, retain old hashed assets for open tabs, and deploy the complete website artifact for a combined website and app.

Validation includes mobile browser layouts, bilingual navigation, offline routing, data preservation and update guards. Physical Android installation and migration remain part of beta acceptance.
