# Holter Diary 0.1.0-beta.4

## Clearer clock settings and report access

- Read clock differences as hours, minutes and seconds, with a clear ahead/behind direction instead of fractional seconds.
- Use the same readable format for saved settings and a pending clock comparison. Differences smaller than one second remain distinguishable from no correction.
- Find Protokoll / Report as an outlined button with a document icon beside the diary heading, including on narrow screens and with enlarged text.

These are presentation changes. Stored calibration precision, original timestamps, report calculations and the installed app identity remain unchanged. No new dependencies or permissions are required.
