Resetting a diary now checks the entries shown in the confirmation against the
saved data immediately before deletion. Changes from another open tab stop the
reset so they can be reviewed first.

Delayed app updates and updates activated in another tab offer a safe reload
action. Unsaved notes and settings remain protected, including edits started
while an update is activating. Storage guidance now explains that installation
can help with persistent storage permission but does not guarantee it.

Release automation preserves queued version publications and can recover
incomplete uploads in matching draft releases. Completed release assets remain
unchanged. No database migration or app identity change is required.
