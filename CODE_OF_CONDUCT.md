# Code of Conduct

Holter Diary welcomes contributors of every background and level of experience.
This code applies to the project's issues, pull requests and other project spaces.

## Working together

- Discuss ideas and code respectfully. Criticism should explain the problem and
  help improve the result, without attacking the person.
- Be patient with newcomers, different languages and accessibility needs.
- Respect privacy. Do not publish someone else's identity, contact details,
  health information or private messages without permission.
- Harassment, discrimination, threats, sexual harassment, personal attacks and
  deliberate disruption are not acceptable.

## Moderation and reporting

The maintainer may request changes, remove harmful content, lock conversations
or block participants. Responses should reflect the severity and repetition of
behavior; serious abuse may lead to an immediate block. Moderation should avoid
repeating private information and explain decisions when appropriate.

For a concern that can safely be discussed publicly, mention
[@nhanus](https://github.com/nhanus) in the relevant discussion or open an issue
linking to it. Do not post sensitive details or evidence in a public report.

For abuse requiring non-public reporting, use GitHub's **Report content** option
or [GitHub's reporting instructions](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
Reports to GitHub Support are handled by GitHub, not a private project inbox.
The project does not currently provide a separate confidential reporting address.
